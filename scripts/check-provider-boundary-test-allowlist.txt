# check-provider-boundary.sh's test-file allowlist.
#
# check-provider-boundary.sh scans every app/**/*_test.go file. Each path
# below is exempted because it predates that scanning and uses one of two
# pre-existing conventions the checker would otherwise flag: a shipped
# plugin name used as a generic placeholder id in a catalog/resolver/
# service test, or an "owner/repo-N"-shaped example session name used as
# the default example session. Neither is a leak this checker was built to
# find (see the leak that motivated it, app/internal/channel's shipped
# channel tests, which are scanned like any other file) — it is unrelated,
# pre-existing debt.
#
# Issue #280 tracks migrating these fixtures off that convention, one
# package at a time; a path is removed from this list only once its file
# no longer trips the checker on its own, never in bulk. The list must
# shrink toward empty, never grow: a new test file belongs in the scanned
# set from the day it is written.
#

# lines starting with "#" are ignored.
